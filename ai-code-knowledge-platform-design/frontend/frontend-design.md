# Frontend Design

## 页面
- Dashboard
- Project
- Commit Review
- Knowledge
- MCP

## Project
Repository、Branch、Contributors、Commit、整体评估、Project Knowledge。

## Commit Review
Commit Message、Diff 摘要、变更文件、影响范围、Finding、风险等级、前后代码片段。

## Knowledge
Project/Personal 分区；支持类型、来源、版本、关系、引用、导出。

## MCP
创建 Profile、选择知识范围、创建/撤销 Token、客户端配置示例。

## 原则
前端不承担 AI 业务逻辑。
